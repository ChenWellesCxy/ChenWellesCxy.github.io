SystemVerilog / UVM 学习资源调研

项目文档快照 · 2026-10-21 · 查看原文 ↗

本轮补充： 深入教材入口是 官方文档学习导航。免费UVM环境以 更新后的选型 为准：Verilator 5.052明确支持UVM 2020-3.2，DSim官方列出可生成的Free Individual License，EDA Playground提供免费在线商业工具。不要把本机旧版5.032的限制外推为当前所有开源工具的限制。

调研日期：2026-10-09。以下资源优先采用标准组织、工具官方文档和项目上游仓库。适合你的目标是先补足“能独立写自检式 SV testbench”的能力，再把同一套验证思想映射到 UVM；DRAM/Finesim 的经验可以作为协议、时序约束、corner case 和回归管理的优势。

建议学习顺序

  1. SystemVerilog 语法与仿真基础：IEEE 1800 标准作查阅手册；配合 SystemVerilog Academy 或 Siemens Verification Academy 的课程，先学 logic、过程块、数组、task/function、interface、clocking block、class、继承和 virtual method。
  2. 验证语言能力：练 transaction/class、queue/associative array、mailbox/event、fork...join、约束随机化、立即断言/并发断言、covergroup、functional coverage。每一章都写一个小的自检 TB，产生 VCD/FST 波形。
  3. 用开源工具做纯 SV 练习：从 systemverilog-homework 开始；再用 Verilator manual 的 --binary 示例及自己的小 DUT/自检 TB。Verilator 和 Icarus 都有语言/验证特性边界，遇到不支持的构造要区分“代码错”和“工具不支持”。
  4. 再学 UVM：先看 Doulos Easier UVM 和 Accellera 的入门视频，按 sequence_item → sequence/sequencer/driver → monitor → agent → env → scoreboard → test 顺序构建 TinyALU 或 FIFO 验证环境。后读 UVM User’s Guide，再查 Class Reference 和源码。不要一开始就读全套类库源码。
  5. 接触真实规模代码：读 Ibex 的 UVM 验证文档与源码，重点看 test/sequence、agent、scoreboard、coverage、testplan 如何对应；其完整 UVM 回归需要商业仿真器及若干依赖，建议作为阅读材料，不作为第一套必须跑通的练习。
  6. 迁移到 DRAM 验证岗位面试：把已有的命令/时序场景改写成 transaction 与 sequence；解释 stimulus、monitor、reference model/scoreboard、coverage、assertion、seed/reproducibility、debug waveform。UVM 是组织方式，不替代协议知识。

Accellera UVM 下载页 官方参考实现与历史版本下载。目前页面列出 UVM 2020-3.2 (2026-08) 及 2020-3.1；学习时固定一种版本。
Accellera UVM 社区页 IEEE 1800.2-2020 对应 UVM 参考实现与社区入口。
Accellera UVM 1.2 User’s Guide PDF 经典逐步入门材料，适合理解架构；版本较旧，读法与现代项目 API 有差异时以项目所用版本/标准为准。PDF 版权页许可该材料采用 Apache 2.0。
UVM Class Reference（Verification Academy 镜像文档） API 查询和继承关系参考；这是 UVM 1.1d 文档，不要误当最新标准。
Accellera：UVM IEEE 1800.2-2020 对齐说明 理解 UVM 1.2 与 IEEE 1800.2 版本关系。
Accellera UVM tutorial: Ready, Set, Deploy! 官方活动页面上的入门视频/教程，覆盖受约束随机验证及 UVM 基础。
Accellera IEEE 1800.2 标准教程 PDF 了解 IEEE UVM 标准化过程和结构，属于概览资料。
Siemens Verification Academy 全部课程 可按 SystemVerilog、Classes、Constraint Solver、UVM 分类学习；也可找 UVM Cookbook 等课程内容。
Doulos Easier UVM 面向可读、可维护 UVM 的免费指南，适合作为第一套 UVM 编码风格参考。
Doulos UVM 入门视频 约 2011 年的概念介绍，年代较早但适合先建立 UVM 组件图景。
SystemVerilog Academy 当前课程目录含 SV、SVA、约束和 UVM 初学者/agent 课程；网站说明旧课程可免费观看。可作通俗课程，标准和上游工具文档用于核对。

可运行项目与工具

项目 推荐用法、运行条件与限制
SystemVerilog Homework 首选练习项目。上游 README 提供 Linux/WSL 脚本，包含自检练习，并能通过 $dumpvars 生成 VCD 用 GTKWave/Surfer 看波形。README 标示 MIT License。运行前记录仓库 commit；不要默认最新主分支永远稳定。
Verilator 官方仓库 与 官方 --binary 示例 开源 SV 仿真/ lint 工具，支持范围持续变化。官方示例展示如何直接编译运行 SV 示例；可加 --trace 生成波形（具体选项按当前手册）。许可证为 LGPL-3.0 或 Artistic License 2.0。完整 UVM 兼容性不能假定；核对所选 Verilator 版本的支持清单。
Icarus Verilog 轻量、适合基础 RTL 与部分 SV 语法/测试平台练习；不适合用来证明完整 class/constraint/UVM 兼容。项目许可证 GPL-2.0-or-later。
SVUT 小型 Verilog/SystemVerilog 单元测试框架，README 描述 Icarus/Verilator 与 VCD/GTKWave 工作流；适合模块级测试。先检查该项目当前支持的语言子集和许可证文件。
brokenBench SV/UVM gotcha 风格练习，偏“观察和修复边界行为”；仓库说明部分练习可能要求特定/打补丁 Verilator，按每个练习标签确认，不要把其所有 UVM 练习都当作 stock 工具可跑。检查 LICENSE 与固定 commit。
Antmicro verilator-uvm-example 推荐作为 UVM 实践补充：该固定版本提供 item、sequence、sequencer、driver、monitor、scoreboard 与 test 的小型 SV UVM 环境；README 给出 Verilator 编译运行命令，并固定示例所用 Accellera UVM 2020.3.1。仓库采用 Apache-2.0。注意这是 Verilator 当前支持子集上的演示，不能据此推断任意 UVM 工程可运行；复现时按此 commit、其所需 Verilator 版本及 UVM 2020.3.1记录环境。
VerificationXpert opensource-uvm 有 Verilator + UVM 的实验性 minimal example，仓库称 MIT；属于探索/实验项目，依赖与 UVM 子集可能随版本变化，作为进阶尝试，不作为基准答案。先固定仓库 commit、Verilator 版本和 UVM 源码版本。
pyuvm TinyALU 可在开源模拟器上体验 UVM 概念的 Python/cocotb 实现，并有 TinyALU 示例；它不是 SystemVerilog UVM，适合旁观 transaction/sequence/scoreboard 结构，不足以替代 SV UVM 编码练习。查仓库 LICENSE 和支持的 simulator 版本。
lowRISC Ibex 验证文档 高质量真实 UVM 环境案例。上游文档说明完整 co-simulation 需支持 UVM 的仿真器，当前验证的完整 flow 使用 VCS/Xcelium，并需 Spike/RISC-V 工具链；Ibex Simple System 另有 Verilator 仿真目标，但那不等价于运行完整 UVM 回归。代码仓库 Apache-2.0，依赖各自许可证需单独检查。
Accellera UVM Reference Implementation 与所选 UVM 标准版本配套的库源码。开源库本身不等于开源仿真器能完整运行 UVM；建议在有许可的 Questa/VCS/Xcelium/Riviera/DSim 等工具上完成正式 SV UVM 练习。

仿真器与波形的实际选择

  • 纯 SV 入门：在 WSL 用 Verilator 或 Icarus 做简单 module、task、过程块、interface 等练习。较高级随机化、covergroup、SVA、UVM 的支持情况依工具版本/构造而变，不能以“编译通过几个例子”推断完整兼容。
  • 标准 SV UVM：使用带 UVM 支持的商用工具/教育版，或 EDA Playground 这类在线环境（需检查当时可用 simulator、运行时长及账号要求）。本地安装 Verilator 并不自动提供完整 UVM 模拟能力。DSim 也可作为可访问的商业/免费额度选项，但额度、许可和版本会变化，应以其官网当前政策为准。
  • 波形：优先让小练习输出 VCD/FST，使用 GTKWave/Surfer 查看时钟、复位、valid/ready、transaction 边界和 checker 采样点。UVM 类层次对象不一定直接映射成硬件波形；通过接口信号、打印日志、transaction recording 和仿真器的 UVM debug 能力联合定位。

固定版本、复现与许可证建议

  1. 每次学习工程把工具版本写在 README：OS/WSL 版本、Verilator/Icarus 版本、UVM 版本、波形查看器版本；命令行保存到脚本或 Makefile。
  2. Git 项目 clone 后记录 git rev-parse HEAD，把上游分支/标签与 commit SHA 存入学习笔记；依赖不要长期追踪 master。学习 UVM 时建议明确写 IEEE 1800.2-2020 / Accellera UVM 2020-3.2，若工具随附的是另一版本则记录实际版本，不混用库文件。
  3. 代码仓库 license 与 UVM 标准/文档 license 是不同事项。分发或公开自己的 fork 前检查每个 repo 的 LICENSE、第三方依赖和波形/示例版权；上表许可证信息来自项目首页/README 中明确说明的条目，未明确列出的应在使用前核对。
  4. 本调研没有读取或复制你的私人 RefProject。后续 SV 教程会按你指定的 CoverageModel 路径分析其结构，但只抽取适合教学的概念与自建练习，避免把专有材料上传到公开仓库。

适合先做的练习

  • 写一个 8-bit counter/FIFO 的 SV 自检 testbench：driver 产生操作，monitor 采样接口，scoreboard 用队列预测，assertion 检查不变量，covergroup 覆盖边界；输出波形并写清楚采样点。
  • 将 driver 的操作封装成 sequence_item 和 sequence，增加 sequencer/agent，再加入 passive monitor 和 scoreboard，比较模块化前后的复用方式。
  • 选择一个与工作无关的公开 DUT（如简单 ALU/FIFO），完整做 directed + constrained-random 测试，保存 seed、日志、波形和 coverage 结果；之后把 DRAM 场景抽象为“命令 transaction 与约束”，练习面试讲解。
